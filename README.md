# CODSOFT Frontend Development Internship

This repository contains the projects completed as part of my **Frontend Development Internship at CodSoft**.

The projects demonstrate my practical skills in **HTML, CSS, and JavaScript**, including responsive design, DOM manipulation, form validation, Local Storage, filtering, and interactive user interfaces.

## 📂 Projects

### Task 1 — Personal Portfolio Website

A modern and responsive personal portfolio website created to showcase my professional profile, skills, projects, resume, and contact information.

**Features:**

* Responsive design
* Home section
* About section
* Skills section
* Projects section
* Resume/CV section
* Contact section
* Responsive navigation menu
* Smooth scrolling
* Hover animations and interactive UI elements
* Contact form validation
* Downloadable Resume/CV

**Technologies:**

* HTML5
* CSS3
* JavaScript

### Task 2 — To-Do List Application

A responsive task management application that allows users to organize and manage their daily tasks.

**Features:**

* Add new tasks
* Edit tasks
* Delete tasks
* Mark tasks as completed or pending
* Local Storage support
* Completed and pending task counters
* Search functionality
* Task filtering
* Task categories
* Priority levels
* Due dates
* Dark mode

**Technologies:**

* HTML5
* CSS3
* JavaScript
* Local Storage

### Task 3 — Personal Expense Tracker

A personal expense tracking application designed to help users manage their income and expenses and view their financial summary.

**Features:**

* Add income transactions
* Add expense transactions
* Transaction history
* Date and category information
* Automatic income calculation
* Automatic expense calculation
* Current balance calculation
* Local Storage
* Edit transactions
* Delete transactions
* Category-based filtering
* Financial summary cards
* Responsive user interface

**Technologies:**

* HTML5
* CSS3
* JavaScript
* Local Storage
